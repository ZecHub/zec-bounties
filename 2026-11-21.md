Valar Group, Project Tachyon, Shielded Labs, ZODL and Zcash Foundation 🛠️

ZODL

* ZODL introduces Private Wallet Servers with OHTTP — ZODL began rolling out new wallet infrastructure using Oblivious HTTP (OHTTP), Cloudflare and Fastly. This separates users’ IP addresses from their wallet requests.
* ZODL official announcement — The team explains its new wallet infrastructure and privacy improvements.
* ZODL Q3 Core Protocol Development Grant — ZODL submitted a $950,000 retroactive grant application covering protocol development, Ironwood, cryptography and wallet infrastructure.

Community Projects 🌐

Wallets and Privacy Applications

* ZODL — A self-custody Zcash wallet with new privacy-focused wallet infrastructure.
* ZecBlock Private — A privacy-focused block explorer using Private Information Retrieval (PIR). It allows users to search transactions, blocks and addresses without revealing the requested record to the server.
* Zillions Keychain — A project working to make Zcash accounts easier to manage.
* Keystone Wallet — A hardware wallet project announcing support for NU7.
* Unstoppable Wallet — Integrated ZODL’s Slipstream synchronization engine and reported a benchmark showing a wallet restoration approximately 21 times faster than its legacy method.
* Vizor Wallet — A cross-platform self-custody wallet for Zcash.
* Zakura — An alternative high-performance Zcash node implementation.
* Zingo Labs — Wallet development, Zcash infrastructure and the Zingod indexer.
* Where’s My ZEC — An open-source tool for checking swap status and refund deadlines without connecting a wallet.
* Veylor — An experimental wallet with a shielded atomic bridge between shielded USDC and shielded ZEC. It is in a limited beta.
* PetraPay — A payment gateway designed to settle merchant payments in shielded ZEC.
* ZecMap — A community project that helps users discover businesses accepting Zcash.
* Zcash Open Wallet Standard — Open-source wallet standards and integration work.
* Free2Z — A platform for creators and community members.
* Zcash Stack — Open-source infrastructure for building with Zcash.
* Zorg Wallet — An experimental terminal-based wallet for users who prefer command-line tools.

Research and Developer Tools

* STARK Verification Prototype — An experimental project measuring the cost of verifying STARK proofs using Zebra regtest.
* Strahn Cryptography — Research into shielded Zcash subscriptions using FROST-based locks. This is not an active mainnet feature and requires further governance approval.
* OpenZcash — A community transparency and ecosystem platform featuring projects, grants, governance and opportunities.
* ZecHub — Educational resources, tutorials, community documentation and ecosystem information.
* Zcash Community Forum — The main place for technical discussions, project announcements and governance proposals.
