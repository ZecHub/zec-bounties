# ZEC Bounties

Privacy-first bounty platform with native shielded ZEC payments. Post tasks, apply, submit work, and get paid without collecting addresses by hand.

## Shielded payouts only

Register a Unified Address that includes a shielded receiver. Transparent-only addresses are rejected. Mixed UAs (shielded + transparent) are allowed with a warning.

See [Addresses](addresses.md) for the full rules.
