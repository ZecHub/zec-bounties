# Badges

Badges appear on the KPI leaderboard and on contributor profiles. They recognize both activity volume and specialized roles in the Zcash bounty ecosystem.

## Task stars (automatic)

Stars are awarded automatically based on the number of bounties a contributor has completed. They replace the old colored member icon.

| Badge | Threshold | Meaning |
|-------|-----------|---------|
| ![1 Task](/badges/Light-Mode/1-task.svg) **1 Task** | 1+ completed | First contribution |
| ![5 Tasks](/badges/Light-Mode/5-tasks.svg) **5 Tasks** | 5+ completed | Consistent contributor |
| ![10 Tasks](/badges/Light-Mode/10-tasks.svg) **10 Tasks** | 10+ completed | Regular participant |
| ![15 Tasks](/badges/Light-Mode/15-tasks.svg) **15 Tasks** | 15+ completed | Strong track record |
| ![25 Tasks](/badges/Light-Mode/25-tasks.svg) **25 Tasks** | 25+ completed | Highly active |
| ![50 Tasks](/badges/Light-Mode/50-tasks.svg) **50 Tasks** | 50+ completed | Top-tier contributor |

Admins can also manually override the star level for a user.

## Specialty badges (manual)

These are assigned by admins to recognize specific roles or achievements.

| Badge | Name | How it is earned |
|-------|------|------------------|
| ![Admin](/badges/Light-Mode/admin.svg) | **Admin** | Platform administrator |
| ![DAO Member](/badges/Light-Mode/dao-member.svg) | **DAO Member** | Active ZecHub / Zcash DAO participant |
| ![Node Runner](/badges/Light-Mode/node-runner.svg) | **Node Runner** | Runs a Zcash full node that supports the ecosystem |
| ![Researcher](/badges/Light-Mode/researcher.svg) | **Researcher** | Contributes research, analysis, or technical write-ups |
| ![Designer](/badges/Light-Mode/designer.svg) | **Designer** | Design / UX / visual contributions |
| ![Developer](/badges/Light-Mode/developer.svg) | **Developer** | Code contributions (PRs, tools, integrations) |
| ![Translator](/badges/Light-Mode/translator.svg) | **Translator** | Localization and translation work |
| ![Writer](/badges/Light-Mode/writer.svg) | **Writer** | Content, documentation, or educational writing |
| ![Hackathon Participant](/badges/Light-Mode/hackathon-participant.svg) | **Hackathon Participant** | Took part in a Zcash-related hackathon |
| ![Hackathon Winner](/badges/Light-Mode/hackathon-winner.svg) | **Hackathon Winner** | Placed or won in a Zcash-related hackathon |

## Notes

- Stars update automatically when a bounty is marked completed.
- Specialty badges are granted by admins via the KPI dashboard (“Manage User Badges”).
- Light and dark variants of every badge exist; the site selects the correct set based on the current theme.
- A user can hold multiple specialty badges at the same time.
